# Zenith Software

Portfolio website for Zenith Software: a single self-contained `index.html`
(English only) with a Three.js 3D scene, a project carousel and project cards.

## Run

Open `index.html` in a browser. Three.js (r128) loads from cdnjs and the fonts
(Syne, Instrument Sans, JetBrains Mono) from Google Fonts, so it needs internet.

## Before going live

- Replace the placeholder email `hello@zenithsoftware.example`.
- Check the pricing timelines and FAQ answers match how you work.
- The contact section shows an email with a copy button; there is no form backend.
